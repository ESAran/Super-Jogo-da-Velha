Etapa 10 - Ordem recomendada de implementação

Criar src/ui/cli/jogo_cli.py e mover a lógica da partida para lá.
Simplificar app.py para chamar só a execução da partida.
Criar src/ui/cli/menu.py.
Criar src/ui/cli/telas.py.
Criar src/ui/cli/app_cli.py para controlar o fluxo do menu.
Fazer app.py passar a chamar a aplicação CLI completa.
Criar src/storage/historico_repository.py.
Criar src/storage/conquistas_repository.py.
Só depois começar a implementar histórico real, conquistas e modo jogador vs máquina.
Benefícios dessa reorganização

Separação melhor entre interface, domínio e persistência.
Menos acoplamento em app.py.
Mais facilidade para crescer o projeto sem transformar a entrada principal em um arquivo grande demais.
Base mais preparada para menu, IA, histórico e conquistas.
